## Журнал изменений реестра

- 2026-08 — **прогон A0 по корректурной пробе** (`2026-08-correction-test.md`).
  Урок: критерий 1 чек-листа (совпадение процедуры) критичен для методик с
  вариантами. Наша ячейка — цифровой Бехтерев (время + М1/М2), а открытый веб
  даёт нормы классического бумажного Бурдона (`procedure_mismatch`). Правильный
  источник — методичка Бехтерева (реестр №6), запрошена у Степана.
- 2026-08 — **прогон A0 по «10 словам»** (`2026-08-ten-words.md`). Эмпирический
  замер доступа из среды: поиск (WebSearch) работает; прямое извлечение
  (WebFetch) отдаёт **403 даже на открытых источниках** (КиберЛенинка, PMC,
  psyjournals) и на обычных PDF. Практический вывод: слой discovery запускаем
  бесплатно уже сейчас; слой extraction (полные нормы) идёт через PDF от Степана
  либо серверный этап A3 (нормальный IP + браузер обходят 403).
- 2026-07 — **реестр утверждён Степаном целиком (9 площадок → active)**;
  его акцент: PubMed и КиберЛенинка — «самые норм из доступных», остальные
  тоже хороши. Ритм утверждён: квартальный дайджест + горячие алерты;
  квартальный триггер прогона — включён; продукт-дайджест — обе версии
  (цена платной — обсуждается отдельно).
- 2026-07 — создан стартовый черновик (9 площадок), пилот-прогон по Шульте
  выявил, что открытые источники (КиберЛенинка, psyjournals, PMC, Минздрав) —
  приоритет обхода; подписные дают только сигнал.
