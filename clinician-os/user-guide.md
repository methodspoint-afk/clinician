# Памятка пользователя — с чего начать

> Короткий онбординг для специалиста (Степан и будущие коллеги). Приложение —
> **поддержка решения**, а не диагноз. **ФИО не хранится** — вы работаете с
> обезличенными кодами. Всё локально в браузере, офлайн.

## За 1 минуту: первый прогон

1. **Выберите профиль.** На стартовом экране введите имя (напр. «Степан») →
   «Войти». Каждый специалист видит только своих испытуемых.
2. **Создайте испытуемого.** «Испытуемые» → «+ Новый испытуемый». Введите
   возраст, образование, пол, при необходимости диагноз (МКБ). **ФИО не вводится:**
   код генерируется сам, связь «код → человек» вы храните отдельно, вне приложения.
3. **Проведите методику.** Откройте карточку испытуемого → «Новое обследование» →
   выберите методику (напр. «Таблицы Шульте», «10 слов») → внесите замеры.
4. **Посмотрите подбор нормы.** Приложение прозрачно выбирает норму: сначала
   отсев по популяции (возраст/образование/язык — **Gate**), потом балл качества
   нормы 0–100 (**Score**). Видно, какая норма выбрана и почему остальные отсеяны.
5. **Сохраните и откройте отчёт.** Отчёт по блокам (внимание / память / мышление),
   динамика повторных обследований, экспорт в `.doc`.

## Что важно понимать

- **Вердикт — это не диагноз.** Формулировки вида «снижение/повышение показателя
  относительно нормы условно здоровых» + степень. Решение всегда за специалистом.
- **Нет валидной нормы?** Приложение не подставит «похожую» тайком: покажет, что
  валидной нормы нет, и ближайшие варианты. Можно применить норму вручную
  (override) — но обязательно с обоснованием, и это будет помечено в карточке.
- **Возраст.** Взрослый диапазон 16–60 — жёсткие границы; внутри допускается
  небольшое растяжение (±10 лет, флаг `age_stretch`). За границами — «нормы нет».

## Общая анонимная база (главная фишка)

- При сохранении результата можно поставить галочку **«поделиться обезличенным
  результатом»**. Тогда точка (без кода, ФИО, комментариев и препаратов) может
  быть выгружена в общую базу — так копятся нормы по диагнозам.
- Обмен — на экране **«Синхронизация»** (только владелец): выгрузка каталога норм
  и обезличенных слепков в файл или на сервер по HTTP; загрузка норм с сервера.
- Смысл проекта — сопоставлять нормы и организовывать сбор данных; общая база это
  и обеспечивает.

## Безопасность данных

- **Резервная копия.** «Настройки» → скачать `.sqlite`. Делайте регулярно.
- **Восстановление — с защитой.** Перед заменой приложение проверит файл, покажет
  сводку содержимого и потребует подтверждения, а текущую базу сначала скачает как
  страховку («…-ДО-восстановления»). Чужой/битый файл будет отклонён, данные не
  тронуты.

## Если что-то не так

- **Офлайн-плашка** сверху — значит нет интернета: выводы строятся только по ранее
  загруженным нормам, общая база и источники недоступны.
- Данные не пропадают между сессиями (хранятся в браузере). Смена
  браузера/устройства — через резервную копию.
